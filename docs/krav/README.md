# Krav

Här beskrivs vad Fotbollsbanken ska göra och för vem.

| Fil | Innehåll |
|---|---|

Varje dokument har en statusrad överst: `Status: utkast` eller `Status: godkänd (K1, ÅÅÅÅ-MM-DD)`.
