# 22. Skriva ut ett pass som PDF

**Roll:** ledare

**Som** ledare **vill jag** kunna skriva ut eller exportera ett pass som PDF med planskisser, **så att** jag kan ha det på papper eller dela det utan att alla behöver appen.

## Acceptanskriterier

1. **Givet** att ledaren har ett sparat eller genererat pass, **när** ledaren väljer att skriva ut eller exportera passet, **då** skapas ett dokument som innehåller passets övningar i ordning, med planskiss, syfte, beskrivning och tid för varje övning.
2. **Givet** att en övning i passet saknar planskiss, **när** dokumentet skapas, **då** visas övningens text ändå, utan att den saknade planskissen orsakar fel i hela dokumentet.
3. **Givet** att dokumentet ska användas på papper, **när** ledaren öppnar det exporterade dokumentet, **då** är det läsbart i vanlig utskrift (även utan färg).
4. **Givet** att ledaren exporterar passet, **då** görs det utan extra kostnad för ledaren, i linje med kravet på gratisnivåer för drift.

## Beroenden

- 02/05 (pass finns), 06/07 (planskisser).

## Utanför denna berättelse

- Klubbanpassad logga eller sidhuvud på utskriften (se backlog, Could).
- Export i andra format än PDF.
