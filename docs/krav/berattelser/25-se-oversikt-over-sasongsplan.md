# 25. Se översikt över säsongsplanen

**Roll:** ledare

**Som** ledare **vill jag** kunna se en översikt över hela säsongsplanen, **så att** jag snabbt kan bedöma om planeringen känns balanserad över tid.

## Acceptanskriterier

1. **Givet** en säsongsplan med flera veckors pass, **när** ledaren öppnar översikten, **då** visas samtliga veckor i kronologisk ordning med sina teman eller fokusområden.
2. **Givet** att ledaren vill se detaljer om en specifik veckas pass, **när** ledaren väljer veckan i översikten, **då** kommer ledaren till det passet.
3. **Givet** att säsongsplanen sträcker sig över en lång period, **när** ledaren tittar på översikten på mobil, **då** kan ledaren bläddra genom perioden utan att gränssnittet blir oanvändbart.

## Beroenden

- 23 (skapa en säsongsplan), 24 (lägga pass i säsongsplanen med progression).

## Utanför denna berättelse

- Jämförelse mellan flera lags säsongsplaner.
- Exportera säsongsöversikten som PDF (kan läggas till som förbättring av berättelse 22, se backlog).
