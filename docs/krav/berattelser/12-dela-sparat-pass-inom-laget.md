# 12. Dela sparat pass inom laget

**Roll:** ledare

**Som** ledare **vill jag** att pass jag sparar för mitt lag syns för andra ledare i samma lag, **så att** vi kan samarbeta om planeringen utan att skicka filer till varandra.

## Acceptanskriterier

1. **Givet** att flera ledare är kopplade till samma lag, **när** en av ledarna sparar ett pass för laget, **då** kan de andra ledarna i laget se och öppna passet.
2. **Givet** att en ledare sparar ett pass utan att koppla det till ett lag (till exempel innan ledaren har något lag), **då** är passet bara synligt för ledaren själv, tills det eventuellt kopplas till ett lag.
3. **Givet** att en ledare inte längre är kopplad till ett lag, **när** ledaren tidigare har sparat pass för laget, **då** finns passen kvar för de kvarvarande ledarna i laget, men ledaren som lämnat ser dem inte längre bland sitt lags pass.

## Beroenden

- 05 (spara ett pass), 10 (klubbadmin hanterar lag), 11 (klubbadmin bjuder in ledare).

## Utanför denna berättelse

- Att markera vem som senast ändrade ett delat pass (se backlog, Could).
- Samtidig redigering av samma pass av flera ledare i realtid.
