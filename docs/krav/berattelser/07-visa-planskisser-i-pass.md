# 07. Visa planskisser för alla övningar i ett pass

**Roll:** ledare

**Som** ledare **vill jag** se planskisserna för alla övningar i ett pass samlade, **så att** jag kan förbereda material och uppställningar för hela träningen i förväg.

## Acceptanskriterier

1. **Givet** ett genererat eller sparat pass med flera övningar, **när** ledaren öppnar passet, **då** visas planskisserna för samtliga övningar, i den ordning de ska genomföras.
2. **Givet** att en eller flera övningar i passet saknar skissdata, **när** ledaren öppnar passet, **då** visas passets övriga planskisser som vanligt, och de saknade markeras tydligt, i stället för att hela vyn slutar fungera.

## Beroenden

- 02 (generera ett träningspass).
- 06 (visa planskiss för en övning).

## Utanför denna berättelse

- Att exportera denna samlade vy som PDF (se berättelse 22).
