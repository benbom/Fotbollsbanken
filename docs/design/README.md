# Design

**Ägare:** ux-designer

Här beskrivs hur Fotbollsbanken ser ut och fungerar för ledaren, både vid planeringen hemma och på planen.

| Fil | Innehåll |
|---|---|
| `floden.md` | Användarflöden för ledare, klubbadmin och redaktör |
| `skisser/` | Wireframes för varje vy |
| `designsystem.md` | Färger, typografi, avstånd och komponenter i ljust och mörkt läge |
| `texter.md` | Gränssnittstexter och felmeddelanden |

Mobilen kommer först (360 px bred skärm). Appen ska klara WCAG 2.2 AA.

Varje dokument har en statusrad överst: `Status: utkast` eller `Status: godkänd (K2, ÅÅÅÅ-MM-DD)`.
